RETIRED - [Apache Maven Shared Incremental](https://maven.apache.org/shared/maven-shared-incremental/)
======================

[![Apache License, Version 2.0, January 2004](https://img.shields.io/github/license/apache/maven.svg?label=License)](https://www.apache.org/licenses/LICENSE-2.0)
[![Maven Central](https://img.shields.io/maven-central/v/org.apache.maven.shared/maven-shared-incremental.svg?label=Maven%20Central)](https://central.sonatype.com/artifact/org.apache.maven.shared/maven-shared-incremental)

This component is retired. It is no longer maintained.
======================================================

The Maven PMC voted to retire it on 2026-09-26
(see the [vote result](https://lists.apache.org/thread/sv5mxh88r3nnn146so7oqpkz0c873mvr)).
The last release, 1.1, stays available on Maven Central.
Its only consumer, maven-compiler-plugin, carries the code itself since
[apache/maven-compiler-plugin#1128](https://github.com/apache/maven-compiler-plugin/pull/1128).

For questions, use the [Maven mailing lists](https://maven.apache.org/mailing-lists.html).
